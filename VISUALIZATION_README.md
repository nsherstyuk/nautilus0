# MTF V2 Replay Visualization Tools

Interactive visualization tools for analyzing MTF v2 replay backtest results using Plotly.

## Available Tools

### 1. `visualize_replay_backtest.py` - Detailed Price & Trade Visualization

Creates interactive candlestick charts with trade markers, showing:
- 1-minute candlestick price action
- Trade entry points (green triangles = long, red triangles = short)
- Trade exit points with P&L labels
- Lines connecting entry to exit
- Cumulative P&L chart
- Interactive zoom and hover information

**Best for:** Analyzing specific time periods or investigating particular trades

**Usage:**
```bash
# Visualize a specific date range
python visualize_replay_backtest.py "optimization_results/optimization_results_20251226_151345/OPT_SL0.8_TP0.8_TR0.4_TH0.65_151347" --start "2025-01-02" --end "2025-01-05"

# Visualize entire backtest period (uses trade min/max dates)
python visualize_replay_backtest.py "optimization_results/optimization_results_20251226_151345/OPT_SL0.8_TP0.8_TR0.4_TH0.65_151347"

# Specify custom symbol
python visualize_replay_backtest.py "backtest_results/MTF_V2_REPLAY_20251227_133941" --symbol EURUSD
```

**Output:** `visualizations/<folder_name>_chart.html`

---

### 2. `visualize_replay_summary.py` - Performance Summary Dashboard

Creates comprehensive dashboard showing:
- Cumulative P&L timeline
- P&L distribution histogram
- Drawdown chart
- Win/loss breakdown by exit reason (TP/SL/etc)
- Individual trade timeline
- Performance by hour of day
- Key metrics summary panel

**Best for:** Quick overview of backtest performance, identifying patterns, and comparing different parameter sets

**Usage:**
```bash
# Create summary for any backtest results folder
python visualize_replay_summary.py "optimization_results/optimization_results_20251226_151345/OPT_SL0.8_TP0.8_TR0.4_TH0.65_151347"

# Or for recent replay results
python visualize_replay_summary.py "backtest_results/MTF_V2_REPLAY_20251227_133941"
```

**Output:** `visualizations/<folder_name>_summary.html`

---

## Requirements

These tools require the following Python packages (already in your environment):
- `plotly` - Interactive charting
- `pandas` - Data manipulation
- `nautilus_trader` - Data catalog access (for detailed charts)

## Input Data

Both tools expect backtest results folders containing:
- `fills.csv` - Execution fills from backtest
- `trades.csv` - Completed trades with entry/exit/P&L

These files are automatically generated by:
- `run_backtest_mtf_v2_replay.py`
- `optimize_mtf_v2_replay.py`

## Output Location

All visualizations are saved to the `visualizations/` directory as interactive HTML files that can be opened in any web browser.

## Tips

1. **For quick analysis**: Use the summary tool first to get an overview
2. **For trade investigation**: Use the detailed chart with specific date ranges
3. **For comparing optimizations**: Generate summaries for multiple parameter sets
4. **Browser performance**: For full backtests (1+ year), use the summary tool as it's much faster

## Visualization Features

### Interactive Controls
- **Zoom**: Click and drag to zoom into specific time periods
- **Pan**: Hold shift and drag to pan
- **Hover**: Hover over elements to see detailed information
- **Toggle**: Click legend items to show/hide series
- **Reset**: Double-click to reset zoom

### Color Coding
- **Green**: Winning trades, long entries, positive P&L
- **Red**: Losing trades, short entries, negative P&L  
- **Blue**: Cumulative P&L line
- **Yellow**: Neutral/warning zones

## Troubleshooting

**Error: "No bar data found"**
- The detailed chart requires data in the NautilusTrader catalog
- Ensure your catalog is populated with 1-minute bars for the date range
- Alternatively, use the summary tool which doesn't require bar data

**Browser is slow**
- Use smaller date ranges with the detailed chart
- Use the summary tool for full backtest analysis
- Consider using Chrome or Firefox for better WebGL performance

**Missing trades**
- Check that `trades.csv` exists in the results folder
- Verify the backtest completed successfully
- Check console output for any error messages
