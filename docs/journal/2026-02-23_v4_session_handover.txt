── STEP B  [can do now, does NOT require download] ──────────────

Implement Purged + Embargoed CV in train_meta_model.py.
This is a CRITICAL fix — current TimeSeriesSplit has label leakage
(100-bar lookahead means adjacent signals share future price paths).

The fix — replace the TimeSeriesSplit CV block with purged folds:

  LOOKAHEAD = 100   # matches LOOKAHEAD_BARS in meta_labeling_ema.py
  EMBARGO   = 5     # matches SMA5 window in feature engineering

  Logic per fold:
    Given train_idx and test_idx from TimeSeriesSplit:
    test_start = min(test_idx)
    test_end   = max(test_idx)
    drop from train_idx any sample i where:
      i >= (test_start - EMBARGO) OR
      i <= (test_end + LOOKAHEAD)    ← labels from these overlap test window

  This will lower reported AUC/Precision — that is correct and expected.
  The previous numbers were inflated by leakage.

  Ask the agent to implement this in train_meta_model.py and update
  Section 6 of TICK_SYSTEM_REFERENCE_2026-02-23.txt accordingly.

7.  QUICK CONTEXT FOR NEW AGENT
════════════════════════════════════════════════════════════════

Previous ML system (v2/v3) used 5m/15m time bars, achieved AUC ~0.55.

New system (v4 Meta-Labeling tick) uses:
  - 1000-tick information-driven bars (not time bars)
  - Two-stage meta-labeling: EMA crossover (Stage 1) → XGBoost filter (Stage 2)
  - 24 microstructure features (tick velocity, spread, order flow, RSI, ATR)
  - Path-dependent TP/SL labels (1.5R TP, 1.0R SL, 100-bar lookahead)
  - V4ModelInference: loads .pkl + _features.json + _threshold.json

The meta-model does NOT predict direction.
It predicts P(win | signal context) at an EMA crossover.
Only trade when P > threshold (auto-loaded from _threshold.json).

Three critical items identified by external review:
  1. Parity calibration was measured on 1 hour — needs 5-day session-stratified remeasure
  2. TimeSeriesSplit has label leakage (100-bar lookahead overlap) — fix with Purged CV
  3. Training data ends 2025-12-31 — top-up for Jan–Feb 2026 before real capital
