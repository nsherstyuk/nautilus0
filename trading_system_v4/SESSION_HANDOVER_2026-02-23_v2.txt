8.  QUICK CONTEXT FOR NEW AGENT
════════════════════════════════════════════════════════════════

Previous ML system (v2/v3) used 5m/15m time bars, AUC ~0.55.

New system (v4 Meta-Labeling tick) uses:
  - 1000-tick information-driven bars (not time bars)
  - Two-stage meta-labeling: EMA crossover (Stage 1) → XGBoost filter (Stage 2)
  - 24 microstructure features (tick velocity, spread, order flow, RSI, ATR)
  - Path-dependent TP/SL labels (1.5R TP, 1.0R SL, 100-bar lookahead)
  - Purged+Embargoed CV (100-bar lookahead + 5-bar embargo per fold)

The meta-model does NOT predict direction.
It predicts P(win | signal context) at an EMA crossover.
Only trade when P > threshold (auto-loaded from _threshold.json).
